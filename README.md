# Ahmed Mostaf Tech — منصة المراجعات الجامعية الذكية

منصة تعليمية متكاملة وسريعة لتقديم المراجعات النهائية لطلاب الجامعات بتجربة مستخدم سينمائية استثنائية (Cinematic UX) وأتمتة كاملة للتسجيل والتحصيل والتقارير عبر وسائل الدفع المصرية (Vodafone Cash & InstaPay) مع لوحة تحكم تفاعلية متقدمة للإدارة.

**آخر تحديث شامل:** نوفمبر 2026

---

## 1. القرارات الأساسية والمعمارية للمنصة

| البند | القرار والتنفيذ |
|---|---|
| **النموذج التشغيلي** | تسجيل مباشر وسلس وفوري للمراجعات بدون تعقيد إنشاء حساب أو خطوات زائدة |
| **التسجيل المتعدد** | إمكانية اختيار مادة واحدة أو عدة مراجعات دفعة واحدة في نفس الطلب بحساب تلقائي للمجموع |
| **وسائل الدفع** | فودافون كاش (`01066843568`) وإنستاباي (`ahmedmostafa@instapay`) مع تتبع ذكي للمدفوعات وأيقونات رسمية SVG |
| **أكواد التسجيل** | توليد كود فريد لكل مادة مسجلة (مثال: `AMT-A1B2C3`) لتتبع الدفع ومطابقة التحويل بدقة |
| **لوحة الأدمن** | إدارة مركزية آمنة ومحمية بالـ RLS للأدمن فقط، بواجهة مظلمة متناسقة وإحصائيات تفاعلية ورسوم بيانية عبر Chart.js |
| **التقارير والمزامنة** | تصدير كشوفات الطلاب بضغطة زر كملف Excel CSV مع ترميز UTF-8 BOM الداعم للغة العربية، بالإضافة لمزامنة Google Sheets عبر Apps Script |
| **التصميم والواجهة** | ثيم سينمائي فخم (Cinematic Dark Mode)، بطاقات Spotlight Glow Cards تفاعلية، أزرار Interactive Hover Button، وفوتر Curtain Reveal |
| **الأيقونات** | الاعتماد الحصري الكامل على مكتبة **Font Awesome 6** وإزالة كافة الـ Emojis من الموقع بالكامل |
| **التقنيات المستخدمة** | Vanilla JavaScript (ES Modules)، HTML5، CSS3 (Tailwind-like tokens)، Supabase BaaS (Auth, Database, Storage, Functions, RLS)، Chart.js |

## 2. ما تم إنجازه وتطويره بالكامل (Changelog & Features)

### 2.1. الصفحة الرئيسية (`index.html` & `home-page.js`)
- **Parallax Hero Section:** هيرو تفاعلي سينمائي مع طبقات شبكية ضوئية وهوية المهندس أحمد مصطفى وشعارات التقنيات ومواد التخصص.
- **3D Flip Stats Counter:** بطاقات إحصائيات متوهجة مع تأثير تقليب ثلاثي الأبعاد (3D Flip) عند مرور الماوس وحساب حي للأرقام الواقعية:
  - 3,800+ ساعة مشاهدة
  - 37,400+ مشاهدة على القناة
  - 29+ محاضرة ومراجعة فيديو
  - 700+ طالب واثق بالجروب الرسمي
- **Interactive Roadmap Curriculum:** مسار خطوات التسجيل التفاعلي بتصميم المنحنى الإبداعي المتجاوب.
- **Isometric 3D Testimonials Wall:** جدار آراء وتقييمات الطلاب بمسارات متحركة بميل آيزومتري سينمائي (Marquee) يتوقف بسلاسة عند مرور الماوس (Pause on Hover).
- **Cinematic Curtain Reveal Footer:** فوتر سينمائي كاشف مستوحى من محركات GSAP والشريط الدوار المائل (Diagonal Strip) خلف الشعار العملاق مع تأثير الـ Aurora Glow.

### 2.2. صفحة استعراض المراجعات (`revisions.html` & `revisions-page.js`)
- هيرو سينمائي مع خط التموج الإبداعي (SVG Wavy Underline) ومؤشر مباشر لنبض التوافر (Live Pulse).
- شريط بحث وفلترة لحظي سريع للبحث باسم المادة أو التخصص.
- بطاقات مراجعات بريميوم بنظام **Spotlight Glow Cards** تتبع حركة الفأرة وتُبرز تفاصيل المادة والسعر والخصومات وحالة الصلاحية.
- فوتر الستارة المنكشفة مع مزامنة الارتفاع ديناميكياً لكافة الشاشات.

### 2.3. صفحة تفاصيل المراجعة (`revision.html` & `revision-page.js`)
- تصميم متكامل بالثيم السينمائي الليلي متناسق بنسبة 100% مع الهوم.
- شبكة مميزات إبداعية متحركة (6 كروت Spotlight متوهجة):
  1. محاضرات فيديو مكثفة وعالية الجودة.
  2. مذكرات وملخصات PDF جاهزة للمذاكرة والطباعة.
  3. حل نماذج امتحانات السنوات السابقة بالخطوات.
  4. روابط وصول سحابية مباشرة عبر Google Drive.
  5. انضمام فوري لمجموعة الواتساب المخصصة للمادة.
  6. توافق كامل مع التوصيف الجامعي المعتمد للترم الحالي.
- بطاقة تسعير وحجز جانبية مثبتة (Sticky Spotlight Card) مع زر `.btn-interactive` وأيقونات الدفع والضمانات.

### 2.4. نموذج التسجيل الذكي (`register.html` & `register-page.js`)
- **تحديد مواد متعددة (Multi-Selection):** إمكانية تحديد مادة أو أكثر مع حساب فوري وذكي للعدد الإجمالي والمبلغ المطلوب.
- **قائمة فروع الجامعة الشاملة:** إضافة جميع فروع الجامعة (24 فرعاً رئيسياً + فرع آخر).
- **تحسينات تجربة المستخدم:**
  - النجمة الحمراء الإلزامية `*` بجانب نص العنوان مباشرة.
  - وضع خطوط التلميح الرمادية أسفل عناوين الحقول بدقة.
  - فحص وتدقيق رقم الواتساب المصري تلقائياً (11 رقماً يبدأ بـ 01).
- بطاقات وسائل الدفع المتوهجة بلون الهوية الرسمي لكل وسيلة (فودافون كاش بالأحمر المتوهج، وإنستاباي بالبنفسجي/الوردي المتوهج) مع شعارات SVG نقية.

### 2.5. صفحة الدفع وتأكيد الحجز (`payment.html` & `payment-page.js`)
- دعم تعدد معرفات التسجيل في الرابط (`?id=ID1,ID2`) مع جمع تلقائي لإجمالي المبلغ وعرض كافة الأكواد.
- بطاقات نسخ رقم فودافون كاش ومعرف إنستاباي بضغطة زر مع تغذية راجعة فورية بأيقونات Font Awesome.
- زر واتساب ذكي يفتح محادثة مباشرة مع المهندس أحمد برسالة نموذجية مكتملة البيانات تلقائياً.

### 2.6. لوحة الإدارة المتطورة للمنصة (`admin/`)
- **صفحة تسجيل الدخول (`admin/login.html` & `admin-login-page.js`):**
  - واجهة فائقة البساطة مخصصة للأدمن فقط (البريد الإلكتروني + كلمة المرور) مع حماية RLS وكارت Spotlight متوهج.
- **لوحة الإحصائيات العامة (`admin/index.html` & `admin-home-page.js`):**
  - كروت إحصائيات متوهجة حية (إجمالي التسجيلات، الاشتراكات المؤكدة، طلبات قيد المراجعة، وإجمالي الأرباح المحصلة).
  - رسوم بيانية تفاعلية متقدمة عبر **Chart.js**:
    - **Line Chart:** حركة نمو التسجيلات اليومية ومعدل الإقبال.
    - **Doughnut Chart:** نسبة وتوزيع وسائل الدفع بين فودافون كاش وإنستاباي.
  - جدول مراقبة حديث يعرض آخر العمليات المباشرة على المنصة بستايل زجاجي داكن.
- **إدارة المراجعات والمناهج (`admin/revisions.html` & `admin-revisions-page.js`):**
  - إضافة مراجعة جديدة وتعديل بيانات المواد الحالية وسعرها.
  - تعيين وتحديث روابط الوصول المحمية لـ Google Drive.
  - تفعيل أو إخفاء المراجعات للطلاب بنقرة واحدة (Publish Toggle).
- **إدارة طلبات التسجيل والتحويلات (`admin/registrations.html` & `admin-registrations-page.js`):**
  - فلاتر متقدمة فورية بالاسم، الهاتف، كود التسجيل، المادة، الفرع، وحالة الدفع.
  - مودال فحص تفاعلي يتيح فحص بيانات الطالب، التواصل عبر واتساب برابط مباشر، اعتماد الدفع (Approve)، وضعه قيد الفحص (Under Review)، أو الرفض مع تدوين السبب.
- **التقارير وتصدير البيانات (`admin/reports.html` & `admin-reports-page.js`):**
  - تصدير كامل وفوري لكشوفات الطلاب بتنسيق Excel CSV يدعم اللغة العربية بنسبة 100% (UTF-8 BOM مع حماية أصفار الهواتف).
- **تنظيف الملفات الزائدة:** حذف كافة ملفات الـ LMS القديمة الزائدة عن الحاجة للحفاظ على خفة وسرعة المشروع.

### 2.7. النظام البصري والأيقونات (Design System)
- **Zero Emojis Policy:** تنظيف كامل للمشروع من كافة الإيموجز العشوائية واستبدالها بنظام أيقونات احترافي وموحد عبر **Font Awesome 6**.
- **Spotlight Cards Engine:** محرك حسابي خفيف في `utils.js` يتبع إحداثيات الفأرة عبر متغيرات CSS (`--mouse-x`, `--mouse-y`) لتوليد إضاءة هالات تفاعلية حول البطاقات.
- **Interactive Hover Buttons:** أزرار زجاجية سائلة مع نقطة مضيئة تتمدد وتتفاعل بسلاسة عند التحويم.

## 4. الخطوات القادمة وخارطة الطريق (Next Steps)

### المرحلة 1: التدشين والتشغيل الحي (Deployment & Environment)
1. **الرفع والاستضافة على Cloudflare Pages أو Vercel:**
   - ربط مستودع GitHub مع Cloudflare Pages للاستفادة من استضافة مجانية سريعة جداً مع CDN عالمي ودعم ملف `_headers`.
2. **ضبط متغيرات البيئة والأمان في Supabase:**
   - التحقق من نشر مفتاح الـ `anon key` العلني فقط في الواجهة.
   - التأكد من إدخال حساب الأدمن في جدول `profiles` وتفعيل `is_admin = true`.

### المرحلة 2: محتوى المواد وبيانات المراجعات (Content Population)
1. **إدخال مراجعات الفصل الدراسي الحالي:**
   - الدخول إلى `admin/revisions.html` وإضافة المواد الفعلية ومذكراتها.
   - ربط روابط Google Drive المباشرة لكل مادة والتأكد من أذونات المجلدات (View only).
2. **مراجعة أرقام التحويل الحقيقية:**
   - مراجعة حساب فودافون كاش وإنستاباي في ملف `assets/js/core/config.js` للتأكد من مطابقتها لأرقامك الحالية.

### المرحلة 3: أتمتة الإشعارات السحابية (Automation & Notifications)
1. **تفعيل إشعار Telegram التلقائي للأدمن (اختياري):**
   - ربط Supabase Webhook أو Edge Function لإرسال رسالة تليجرام فورية لهاتفك بمجرد قيام طالب بتسجيل طلب جديد (اسم الطالب، المادة، المبلغ).
2. **تفعيل إرسال إيميل التفعيل الآلي للطلاب (Transactional Email):**
   - تفعيل Supabase Edge Function `send-activation-email` عبر مزود بريد مجاني (مثل Resend أو Google Apps Script) لإرسال رابط Google Drive وكود الاشتراك لإيميل الطالب فور ضغطك على "قبول الدفع".

### المرحلة 4: تحسينات متقدمة مستقبلية (Future Enhancements)
1. **ربط بوابة دفع إلكتروني مباشر (Kashier / Fawry / Paymob):**
   - إمكانية إضافة الدفع بالفيزا والمحافظ مع الـ Webhook للتأكيد الآلي اللحظي 100% دون الحاجة لمراجعة الإيصال يدوياً.
2. **نظام الكوبونات والخصومات:**
   - إمكانية إنشاء كود خصم للطلاب أو لجروبات الدفعة من لوحة الإدارة وتطبيقه في صفحة التسجيل.
